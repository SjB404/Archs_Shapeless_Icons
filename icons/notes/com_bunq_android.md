# bunq (version 7)
Arch (M10): "bunq logo should have a 2x2 grid of letters: bu nq". M11: full colour range, slightly thicker letters.

- Letters: Simple Icons "bunq" wordmark letterforms, rearranged as "bu" over "nq" (the bottom pair moved left and one
  letter-gap down). Each letter gets an extra 0.35-unit outline in its own colours, so the strokes are slightly bolder;
  letter spacing grows by the same amount, so the gaps stay as in the wordmark.
- Colours: the full 12-colour stripe range from the app's own icon background (export bg.png): #008145 #2e9c47 #61b54f
  #8acc54 #3db8ad #3394d6 #2973bd #1a59a3 #ad084d #d91c3d #f05e26 #faa330. Version 6 only had the 10 middle ones
  (the round launcher mask hides the outer two). They run once through the letters in reading order, three stripes per
  letter (b greens, u light green/teal/blue, n blues/magenta, q red/orange/yellow). The stripes are hard-edged
  (gradient stops at the same place), so no soft gradient.
